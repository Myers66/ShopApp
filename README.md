# ShopApp – веб-приложение для управления пользователями и товарами

## Описание
Проект представляет собой простое веб-приложение с авторизацией и ролями (USER / ADMIN).  
Администратор может управлять пользователями (CRUD) и товарами (CRUD).  
Обычный пользователь может только просматривать товары.

Приложение реализовано на чистой Java без фреймворков (Spring, Hibernate и т.п.).  
Используется встроенный HTTP-сервер из JDK, JDBC для работы с БД H2, многопоточное логирование, BCrypt для хэширования паролей.

## Технологии
- Java 11
- Maven
- H2 Database (встроенная)
- JDBC
- Встроенный HTTP-сервер (com.sun.net.httpserver)
- BCrypt
- JUnit 5 (юнит-тесты)

## Запуск
1. Установите JDK 11+ и Maven.
2. Склонируйте репозиторий:  
   `git clone https://github.com/Myers66/ShopApp.git`
3. Перейдите в папку проекта: `cd ShopApp`
4. Соберите проект: `mvn clean compile`
5. Запустите главный класс:  
   `mvn exec:java -Dexec.mainClass="ru.ifmo.project.Main"`  
   или запустите `Main.java` в IDE.

После запуска откройте браузер и перейдите на: [http://localhost:8080](http://localhost:8080)

## Тестовые данные
- Администратор создаётся автоматически при первом запуске:  
  Логин: `admin`  
  Пароль: `admin`
- Новых пользователей можно зарегистрировать через веб-интерфейс (кнопка "Регистрация" на странице входа).

## Реализованные концепции (для зачёта)
- Инкапсуляция (private поля + геттеры/сеттеры)
- Наследование (BaseEntity → User, Product)
- Полиморфизм (интерфейсы GenericDao, UserDao, ProductDao)
- Перегрузка методов (findByName в DAO)
- Рекурсия (в консольном меню, оставленном в коде как демонстрация)
- Вложенные классы (Session в AuthService)
- Исключения (свои DataAccessException, AuthenticationException)
- Многопоточность (LoggingService + LoggerThread с BlockingQueue)
- Потоки ввода/вывода (чтение properties, запись логов)
- JDBC (прямая работа с H2)
- Дженерики (GenericDao<T>)
- Абстрактные классы (BaseEntity)
- Unit-тесты (JUnit 5 для UserDaoImpl)

## Структура БД
- Таблица `users` (id, username, password_hash, role, full_name, created_at)
- Таблица `products` (id, name, price, description, stock_quantity)

## Логирование
Все действия пользователей (вход, выход, CRUD операции) записываются в файл `app.log` в корне проекта. Логирование выполняется в отдельном потоке с использованием `BlockingQueue`.

## Примечание
Проект выполнен в учебных целях. Веб-сервер встроенный, сессии реализованы через Cookie. Никакие сторонние фреймворки не используются.
